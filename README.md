# 🪄 Детски AI Асистент: Магическа кутия за учители

Модерна интерактивна уеб платформа за практическа квалификация и демонстрация на живо пред учители на тема: **„Изкуственият интелект в работата на учителя в детската градина“**.

## ✨ Основни възможности

1. **🎲 Модул 1: „Магическа кутия с игри“ (Генератор на ситуационни игри за 30 секунди)**
   - Интерактивно табло за избор на **Възрастова група (1-ва до 4-та)**, **Настроение в групата**, **Място**, **Време** и **Ресурси** (+ по желание специална дума от публиката).
   - Генерира 3 персонализирани игри, всяка с:
     - **📜 Римувано правило или гатанка за старт** (четиристишие за мигновено привличане на вниманието + бутон за гласово прочитане).
     - **🎯 Как се играе** (ясни стъпки, адаптирани към възрастта).
     - **💡 Педагогическа цел и методически съвет**.
     - Бутони **📋 Копирай** и **🖨️ Принтирай**.

2. **🚀 Модул 2: „Жива демонстрация: Пълна подготовка за 10 секунди“ (Генератор по тема от ДОС)**
   - Избор на **Група** и **Образователно направление** (БЕЛ, Околен свят, Математика, Изобразително изкуство, Музика, Конструиране и технологии).
   - Въвеждане на **произволна тема на живо от залата** или бърз избор с 1 клик.
   - Едновременно генериране на 3 секции (изглед в 3 колони или фокусиран таб за проектор):
     - **📋 1. План-конспект на педагогическа ситуация** (Образователно ядро, Цели, Очаквани резултати по ДОС – Знания, Умения, Отношения, и Ход на ситуацията по минути).
     - **🧚 2. Авторска приказка / История към темата** + **3 въпроса за беседа**.
     - **💌 3. Бележка за родителите (за таблото или Viber групата)** + **5-минутна игра за вкъщи**.

3. **🛡️ Вграден Интелигентен Демо Режим + Реален AI API Режим**
   - Работи веднага **без API ключ и без интернет риск** по време на презентация пред публика.
   - Възможност за свързване на реален **Google Gemini** или **OpenAI API ключ** от модала `⚙️ Настройки за AI` с автоматичен резервен (fallback) режим.

## 🚀 Стартиране на проекта

```bash
npm install
npm run dev
```
